# Namma Yatri – Data Analysis Project

This repository contains our Power BI-driven data analysis project for **Namma Yatri**, an open mobility platform.

## 📌 Objective

Analyze operational data to uncover inefficiencies, optimize pricing, improve driver allocation, and promote digital payments using interactive dashboards and data-driven insights.

## 📊 Contents

- `Namma_Yatri_Data_Analysis.pbix` – Power BI dashboard file
- `Namma_Yatri_Technical_PPT1.pptx` – Technical methodology presentation
- `Namma_Yatri_Business_PPT2.pptx` – Business-focused summary
- `Methodology Report ADV Namma Yatri.docx` – Detailed documentation
- `Namma_Yatri_Data_Analysis_Dashboard.pdf` – PDF snapshot of dashboards

## 🛠 Tools Used

- Microsoft Power BI
- Power Query (ETL)
- DAX (Data Analysis Expressions)

## 🔍 Key Insights

- High trip drop-off rates due to pricing uncertainty
- Demand-supply gaps across zones
- Digital payments adoption trends
- Driver utilization patterns

## 📈 Outcomes

- Data-backed recommendations for predictive pricing
- Enhanced driver allocation models
- Strategies to increase UPI usage
